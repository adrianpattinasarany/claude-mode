# claude-mode

Claude Code mods.

| Mod | What it does |
| --- | --- |
| [prompt-master](plugins/prompt-master) | Rewrites your rough prompt into a clear, well-structured one before you send it: a ✨ button above the prompt box, a `pm:` prefix, and `/pm on` auto mode. |

## Install

At the prompt of a Claude Code session:

```
/plugin install prompt-master --marketplace adrianpattinasarany/claude-mode
```

From a shell:

```bash
claude plugin install prompt-master --marketplace adrianpattinasarany/claude-mode
```
